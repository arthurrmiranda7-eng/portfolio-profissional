## 📝 Sobre o Projeto

Este projeto consiste no desenvolvimento de um portfólio profissional interativo, criado para apresentar minha trajetória acadêmica e profissional, projetos, experiências e formas de contato.

A proposta visual utiliza como conceito principal a experiência de entrada em um estádio de futebol. O usuário inicia sua jornada do lado de fora do estádio e, por meio da rolagem da página, avança em direção à entrada, percorre um túnel que representa diferentes momentos da minha trajetória e, ao final, chega ao campo.

Ao chegar ao gramado, a câmera assume uma visão superior e o campo se transforma na principal interface de navegação do portfólio, permitindo acesso às seguintes áreas:

- **Sobre Mim**
- **Projetos**
- **Experiências**
- **Contato**

Além da navegação pelo campo, o cabeçalho contará com um menu que permitirá acesso direto às principais seções do site.

> **Observação:** os textos presentes nos wireframes são ilustrativos e poderão ser alterados durante as próximas etapas de desenvolvimento, conforme a definição do conteúdo final do portfólio.

## ⚙️ Funcionalidades Previstas

- Experiência inicial baseada em rolagem, simulando a entrada no estádio e o avanço pelo túnel.
- Transição visual progressiva entre o túnel e o campo.
- Campo de futebol utilizado como interface principal de navegação.
- Menu no cabeçalho com acesso direto às principais seções.
- Página **Sobre Mim** com apresentação em português e inglês.
- Página **Projetos** com timeline organizada do projeto mais antigo ao mais recente.
- Exibição de nome, descrição, tecnologias, link para o GitHub e imagem/GIF de cada projeto.
- Página **Experiências** com timeline contendo instituição, atividade, período, descrição e espaço para imagem ou logotipo.
- Página **Contato** com links para e-mail, GitHub, LinkedIn e WhatsApp.
- Formulário de contato com campos de nome, e-mail e mensagem.
- Navegação de retorno das páginas internas para o campo principal.
- Interface responsiva para diferentes tamanhos de tela.

## 🗂️ Estrutura Inicial do Site

O portfólio será organizado em uma experiência principal de navegação e quatro áreas de conteúdo.

### Experiência principal
1. Introdução com o Mineirão
2. Aproximação ao estádio
3. Entrada no túnel
4. Linha do tempo da trajetória
5. Saída para o gramado
6. Elevação da câmera
7. Visão superior do campo
8. Campo interativo como menu principal

### Áreas do portfólio
- **Sobre Mim**
- **Projetos**
- **Experiências**
- **Contato**

### Navegação
O usuário poderá navegar pelo portfólio de duas formas:
- através dos pontos interativos presentes no campo;
- através do menu fixo no cabeçalho.

As páginas internas contarão com a opção **“Voltar ao campo”**, permitindo retornar à interface principal de navegação.
